# Historial de versiones

Mantén este documento actualizado cuando publiques una nueva IPA. No anuncies funciones hasta verificar la versión distribuida.

## [2.4.0] — versión preparada para publicación

- Protección adicional para los recursos de la interfaz Web en el paquete de la aplicación.
- Conserva las funciones de Música compacta, Ecualizador PRO y Biblioteca de versiones anteriores.
- Mejoras continuas de estabilidad.

> Esta nota describe el proyecto trabajado. Verifica que tu IPA final incorpora estos cambios antes de usar `v2.4.0` como etiqueta de Release.

## [2.3.8]

- Conserva los controles de ecualización y ganancia digital.

## [2.3.7]

- Ecualizador de cinco bandas y perfiles de sonido.
- Ganancia digital de hasta 200 % para el reproductor de Música.
