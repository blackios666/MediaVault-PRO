## ✨ ¿Qué es MediaVault PRO?

MediaVault PRO reúne herramientas de descarga compatibles, reproducción musical y organización de archivos en una interfaz oscura y compacta pensada para iPhone. Está diseñada para funcionar sin jailbreak y no necesita un servidor propio para procesar el contenido.

> **Importante:** la disponibilidad de una descarga depende del sitio, del tipo de contenido y de sus restricciones. Utiliza la aplicación únicamente con contenido que tengas derecho a descargar.

## 🚀 Características

| Área | Funciones |
|---|---|
| 📥 **Descargas** | Gestión de descargas de vídeo y audio desde fuentes compatibles; compatibilidad dependiente de cada plataforma. |
| 🎵 **Música** | Reproductor MP3, carátulas, listas, favoritos y reproducción en segundo plano. |
| 🎚️ **Ecualizador PRO** | Cinco bandas, perfiles de sonido y ganancia digital ajustable hasta 200 % dentro de la app. |
| 🗂️ **Biblioteca** | Búsqueda, ordenación, miniaturas y administración de descargas. |
| 📱 **Interfaz** | Diseño oscuro, adaptable y optimizado para pantalla táctil. |
| 🔒 **Distribución** | Código fuente de la app separado del repositorio público de descargas. |

## 📱 Instalación

1. Descarga el archivo `.ipa` desde **Releases**.
2. Firma e instala el archivo con un método compatible con tu dispositivo y las reglas de iOS.
3. Abre MediaVault PRO y utiliza las secciones Descargar, Biblioteca, Música y Ajustes.

**Una IPA descargada desde Safari no se instala automáticamente.** La firma válida y la compatibilidad del dispositivo son requisitos independientes.
